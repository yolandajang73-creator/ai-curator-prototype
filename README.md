# AI 主理人 · 服饰垂类原型

把淘宝有审美/有供应链/会直播的服饰主理人炼成 **AI 分身**，让用户通过对话获得个性化穿搭推荐。

## 在线预览

如果开了 GitHub Pages，访问：`https://<你的用户名>.github.io/ai-curator-prototype/`
否则 clone 后双击 `index.html` 即可。

## 4 个核心交互场景

| 入口 | 类型 | 形态 |
|------|------|------|
| 520 约会穿什么 | 场景型 | 多 AI 主理人卡片栈，滑卡选择 |
| 推荐甜酷风衣服 | 风格型 | 同风格 AI 主理人比拼栈 |
| 赵大喜上新了 | 定向型 | 1V1 对话，横向商品流 |
| 衣橱里少一件什么 | 诊断型 | 多 AI 联合诊断 + 横向缺口卡 |

跨家组合页演示了 3 位 AI 主理人协同搭配（这是平台才能做、单 agent 做不到的能力）。

## 设计原则

- **AI 主理人，不是 AI 客服**：每位主理人有独立审美、声音、信誉
- **多 agent 并行 + 差异化排序**：最匹配 / 风格挑战 / 价格补全 三档
- **解释性**：每张卡片回答"为什么是你"，从算法推荐升级为审美对话
- **跨家编排**：单品来自不同主理人，整套 look 由平台撮合

## 技术说明

纯静态 HTML，无任何依赖。设计稿性质，可直接评审、二次修改。
